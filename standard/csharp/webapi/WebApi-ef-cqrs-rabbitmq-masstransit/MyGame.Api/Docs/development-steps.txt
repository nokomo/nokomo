ORM

- create enity classes in a Models folder
- add entity framework nugets
-- Microsoft.EntityFrameworkCore.Sqlserver
- create dbcontext file
- Install dotnet-ef tools from nuget.org
- run "dotnet tool install --global dotnet-ef --version 10.0.11" in terminal
- add export PATH="$PATH:/home/nokomo/.dotnet/tools" to ~/.bashrc
- Add Microsoft.EntityFrameworkCore.Design 
- Create Mgration using 
  "dotnet ef migrations add InitialCreate --output-dir Data\Migrations" in terminal
- run "dotnet ef database update" in terminal
- create a db migration extension method and invoks it in main program.
- add data seeding in AddSelServer in main program.
- roll back of migration
  -- Only if the migration has been applied to database and not last migration:
     -- Roll back the database: dotnet ef database update <Name_Of_Previous_Migration>
  -- Delete the migration files: dotnet ef migrations remove
  
  -- if only one migration: dotnet ef database update 0 and dotnet ef migrations remove

//--------------------- docker containers --------------------
use "docker compose up -d" in termial to start all services in docker-compose.yml file
use "docker compose down" i terminal to stop all services in docker-compose.yml file
docker container ls to list all containers that are running now
docker container start/stop/rm <container-name> to start or stop or remove a container. 

//------------------------ Runinng the application -------------------------------
docker compose up -d
cd ../MyGame.Api
dotnet run
How to use or see web api operations: 
  - Start a browser and point to http://localhost:5084/scalar/ or use MyGames.http file (part of Rest Client extension) in the root of the application
  - Use DBeaver CE desktop to see data in the Postgres database.

//------------------ .vscode -------------------
To start up Api and worker projects you need to create a launch.json in .vscode folder
{
  // Use IntelliSense to learn about possible attributes.
  // Hover to view descriptions of existing attributes.
  // For more information, visit: https://go.microsoft.com/fwlink/?linkid=830387
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Launch MyGame.Api",
      "type": "dotnet",
      "request": "launch",
      "projectPath": "${workspaceFolder}/WebApi-ef-cqrs-rabbitmq-masstransit/MyGame.Api.csproj"
    },
    {
      "name": "Launch MyGame.Worker",
      "type": "dotnet",
      "request": "launch",
      "projectPath": "${workspaceFolder}/WebApi-ef-cqrs-rabbitmq-masstransit/MyGame.Worker.csproj"
    }
  ],
  "compounds": [
    {
      "name": "Launch All (API & Worker)",
      "configurations": [
        "Launch MyGame.Api",
        "Launch MyGame.Worker"
      ],
      "stopAll": true
    }
  ]
}
